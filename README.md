# Simple Calculator

A basic calculator built with HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, division
- Decimal numbers
- Clear button
- Error handling (e.g. division by zero)

## Live Demo
https://zaki-19.github.io/simple-calculator/

## Technologies
- HTML5
- CSS3 (Grid)
- JavaScript
